# nanogpt-community

Hub for unofficial community projects based around [nano-gpt.com](https://nano-gpt.com).

## Projects

### NanoChat

[nanochat](https://github.com/nanogpt-community/nanochat) is a T3.chat clone using the [nano-gpt.com](https://nano-gpt.com) API

### NanoChat-Desktop

[nanochat-desktop](https://github.com/nanogpt-community/nanochat-desktop) is a native desktop application for nanochat

### NanoChat-Android

[nanochat-android](https://github.com/jcrabapple/nanochat-android) is a native android application for nanochat

### NanoChat-iOS / MacOS

[nanochat-ios](https://github.com/nanogpt-community/nanochat-ios) is a native iOS/iPadOS/MacOS application for nanochat

### NanoCode

[nanocode](https://github.com/nanogpt-community/nanocode) is a opencode fork using the [nano-gpt.com](https://nano-gpt.com) API

### NanoGPT-Discord

[nanogpt-discord](https://github.com/nanogpt-community/nanogpt-discord) is a discord bot for [nano-gpt.com](https://nano-gpt.com)

### ZSH-NanoGPT
[zsh-nanogpt](https://github.com/nanogpt-community/zsh-nanogpt) is a zsh plugin using the  [nano-gpt.com](https://nano-gpt.com) API

### Fish-NanoGPT
[fish-nanogpt](https://github.com/nanogpt-community/fish-nanogpt) is a fish plugin using the  [nano-gpt.com](https://nano-gpt.com) API

### NanoProxy
[nanoproxy](https://github.com/nanogpt-community/NanoProxy) is a proxy for OpenCode and similar coding clients when NanoGPT native tool calling is unreliable

### NanoGPT CLI/TUI
[nanogpt-cli](https://github.com/nanogpt-community/nanogpt-cli) is a rust based agentic CLI/TUI using the [nano-gpt.com](https://nano-gpt.com) API

### Obsidian-NanoGPT
[obsidian-nanogpt](https://github.com/nanogpt-community/obsidian-nanogpt) is a obsidian plugin using the [nano-gpt.com](https://nano-gpt.com) API

### Nano-Zed
[nano-zed](https://github.com/nanogpt-community/nano-zed) is a Zed Fork using the [nano-gpt.com](https://nano-gpt.com) API
